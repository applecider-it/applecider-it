# AppleCider

## ハンドルネームの由来

ハンドルネームを考えないといけないときに、たまたま飲んでいた飲み物。

## ハイブリッドMPAとは？

SPAだとSEO、Node SSRだとスレッドセーフ、Node SSGだとメンテナンスコストと、いたちごっこになっていった結果、Rails,LaravelのMPAが再評価され始めている。

ViteでJSフレームワークを埋め込んだり、Livewire, Hotwiredを使って、アイランドアーキテクチャで、インタラクティブな機能も可能にしたのを、ハイブリッドMPAというそうです。

アイランドアーキテクチャは、普通にHTMLに部分的にJSを埋め込むことです。
